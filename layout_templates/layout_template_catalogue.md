## Additions and why they were added

- **`L45` Section Divider** - Gap: the original 44 only had a first slide and a last slide, so a long deck had no way to signal 'we are now in part two'.
- **`L46` Feature Matrix** - Gap: L07 covers a data table, but a capability / option comparison matrix (the classic 'we vs them' slide) had no archetype.
- **`L47` How-To / Numbered Steps** - Gap: L10 is a horizontal pipeline; a vertical, instructional how-to with enough room for detail was missing.
- **`L48` Hero Metric + Support** - Gap: L05 shows 2-4 equal metrics; a single dominant KPI with a supporting strip is the most common exec slide and was missing.
- **`L49` Pricing Tiers** - Gap: no archetype for a packaging / pricing comparison slide.
- **`L50` Mission / Vision / Values** - Gap: strategy and culture statements had no archetype.
- **`L51` Customer Personas** - Gap: L13 introduces real people (the team); personas describe audiences and needed a different treatment.
- **`L52` Business Model Canvas** - Gap: a widely used strategy frame with no archetype.
- **`L53` Progress / Status Bars** - Gap: L31 is a KPI scorecard; a simple progress readout was missing.
- **`L54` Heatmap Matrix** - Gap: no archetype for intensity-over-two-dimensions visuals.
- **`L55` Scatter / Correlation** - Gap: the catalogue had bar, waterfall and funnel charts but no scatter plot.
- **`L56` Composition / Stacked Share** - Gap: no archetype for a 'split of the total' visual.
- **`L57` Kanban Board** - Gap: L23 maps initiatives over time; live work-in-flight is different.
- **`L58` Retrospective Board** - Gap: team retrospective slides are common and had no archetype.
- **`L59` Key Dates Calendar** - Gap: L23 is a swimlane and L06 a timeline; a dated calendar view was missing.
- **`L60` RACI Responsibility Matrix** - Gap: L37 covers branching decisions, not role accountability.
- **`L61` Anatomy / Labelled Callout** - Gap: no archetype for an explained diagram with labels.
- **`L62` Key Takeaways** - Gap: the catalogue could end a section but had no explicit 'takeaways' archetype.
- **`L63` Contact / Directory Grid** - Gap: L13 shows bios; a contact directory is a different job.
- **`L64` Icon Benefit Strip** - Gap: L03 uses cards; a lighter, more visual benefits row was missing.
